# Truth Lens

Truth Lens is a Next.js app for turning factual claims into transparent verification briefs. It helps a reviewer decide whether a claim is specific, sourced, and ready for human fact-checking.

## What is included

- A responsive browser app built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.
- A claim submission flow with source notes.
- Local evidence-readiness scoring based on specificity, source context, measurable language, and loaded wording.
- Empty and error states for the review brief.
- A sample review queue and method explanation.

The app does not call an external AI or fact-checking API. It produces a triage brief, not a final truth verdict.

## Run locally

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Open the printed local URL in your browser.
