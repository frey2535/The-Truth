# The Truth

The Truth is a Christian reading app that places Christian text and scientific text side by side. It is designed for daily reflection, worship, and wonder at God's creation.

## What is included

- A responsive browser app built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.
- Scripture passages from the King James Version.
- Christian reflections connected to each passage.
- Scientific text about creation, light, life, water, the heavens, and the mind.
- Prayer prompts and a local session journal.

The app does not use external APIs, AI services, authentication, a database, or secret keys.

## Run locally

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Open the printed local URL in your browser.

## Scripts

- `npm run dev` - start the development server
- `npm run build` - create a production build
- `npm run start` - run the production server
- `npm run lint` - run ESLint
